# 工作空间优化

[![License: CC BY-NC-SA 4.0](https://img.shields.io/badge/License-CC_BY--NC--SA_4.0-blue)](LICENSE)

一个给 AI 助手用的技能：让持续几天、几十轮的项目**不失忆**。

进度看得见、决定可追溯、换个对话三十秒接上。

> 一个「技能」就是一份写给 AI 的操作手册：它规定 AI 在特定场景下该怎么走流程，而不是每次临场发挥。

## 它解决什么问题

用多轮对话做一个持续几天的项目，最大的敌人不是 AI 不够聪明，是**失忆**：

- 上次改到哪一步了？
- 当时为什么这么定，能不能改？
- 这个文件还有人用吗，删了会不会出事？
- 换了新对话，怎么让它三十秒内接上？

「工作空间优化」就是给 AI 装一套**项目记账本**：进度看得见、决定可追溯、换对话接得上。

## 它管什么

分五组，每组一件事：

| 组 | 你说什么 | 它做什么 |
|---|---|---|
| 铺骨架 | 「启动项目：XX」 | 先问两个问题（文本型还是代码型、做一次还是反复改），按档位铺；默认只建 `output/`，不整套铺 |
| | 「接手项目，路径：X」 | 只读盘点 → 问三件事 → **铺全骨架** → 归位 → 倒填现状 → 落记录 |
| 对齐 | 「升级项目」 | 技能规则更新后，把老项目的规则副本整体换掉，模板只补不覆盖 |
| 每回合 | 「开工」／「继续做」 | 按预算读文件 → 提提醒 → 三行现状 → 等你确认 |
| | 「收尾」 | 核对产物 → 刷新看板 → 清退废弃件 → 出一张分区表 |
| 维护 | 「瘦身」／「体检」／「卡了」 | 超阈值的文件迁出；目录五项＋体积六项体检；按换会话的三条线自查 |
| 删东西 | 「清空重做，只留 XX」 | 出两份清单 → 逐条点头 → 整目录备份 → 分批走回收站 |

附带一个体检脚本：只读扫目录膨胀、孤儿文件、体量超标，不合格项标 ⚠️。

## 它怎么运转

<img src="docs/skill-architecture-flow.svg" alt="架构与数据流转：一句话触发 → SKILL.md 路由 → 五个执行件按需读 → 落盘到项目 → 下一轮开工读副本" width="100%">

一句话触发 → 主入口路由 → 按需读细节 → 产物落进项目目录 → 下一轮「开工」从落盘处接上。

主线上的光点是数据流，底下那条虚线是回环。**技能本身不存状态**：状态全部落在项目里（规则副本、看板、项目宪法、记忆），所以换一个对话，读回那几份文件就能接上。

## 装上它

技能是**目录**形式的。把整个仓库目录拷到客户端的技能目录下：

```bash
git clone https://github.com/foryys/workbuddy-z-kongjian.git
```

| 系统 | 位置 |
|---|---|
| Windows | `%USERPROFILE%\.workbuddy\skills\workbuddy-z-kongjian\` |
| macOS / Linux | `~/.workbuddy/skills/workbuddy-z-kongjian/` |

把 clone 下来的 `workbuddy-z-kongjian` 整个文件夹放进去即可。

**目录名必须保持 `workbuddy-z-kongjian`** —— 它与 `SKILL.md` 里的 `name` 字段一致，改名会导致技能加载失败。

装好后开一个新会话生效。想让 AI 干活时说人话即可：`启动项目：XXX`、`收尾`、`瘦身`。

## 技能包里是什么

```
workbuddy-z-kongjian/
├── SKILL.md                 主入口：只做路由，不装细节（AI 每一回合都读这份）
├── references/              五个执行件，按「你要干的动作」切
│   ├── 铺骨架.md            空项目怎么铺、已有项目怎么接手、已铺的怎么升级
│   ├── 开工与收尾.md        会话开始四步、结束五件事、日志归档三件套
│   ├── 判据与阈值.md        所有可判数字的唯一出处：体量、目录、去留、卡顿
│   ├── 删除与归档.md        回收站唯一通道、分级收口、清空重做、归档三条
│   ├── 并行判断.md          动手前三步取证，三证齐则删除暂停
│   └── project-rules.md     规则原件，复制进项目后自包含
├── assets/                  模板：铺骨架时复制出去的
│   ├── WORKBUDDY.md         项目宪法模板
│   ├── 工作空间规则-本项目.md
│   └── 看板.html            项目看板模板
├── scripts/
│   └── 体检.py              只读体检脚本
└── docs/
    └── skill-architecture-flow.svg   上面那张架构图
```

## 环境要求

- 面向支持 `SKILL.md` 格式的客户端
- 体检脚本需要 **Python 3.8+**，只用标准库，无第三方依赖
  ```bash
  python scripts/体检.py [项目根目录]   # 不传则体检当前目录
  ```
- 不少条目来自 **Windows** 实测（盘符、回收站、命令行编码），集中在 `references/删除与归档.md` 与 `references/判据与阈值.md`。macOS / Linux 上这部分不完全适用，按需忽略。
